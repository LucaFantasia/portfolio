01 Machine Learning

CDC BRFSS Diabetes Analysis

An exploratory data, statistical and machine learning analysis of a 2015 CDC BRFSS diabetes dataset, investigating health factors associated with diabetes and comparing classical models under a heavily imbalanced dataset.

Python Jupyter pandas scikit-learn XGBoost Streamlit
Final model

Weighted XGBoost was selected for its strong PR-AUC while substantially improving balanced accuracy and minority-class recall.

Live Dashboard GitHub
